新增模型提供商：
打开配置文件：nano ~/.openclaw/openclaw.json
添加提供商相关配置：
`"volcengine-agent-plan": {
        "baseUrl": "https://ark.cn-beijing.volces.com/api/plan/v3",
        "apiKey": "<apiKey>",
        "api": "openai-responses",
        "models": [
          {
            "id": "glm-5.2",
            "name": "glm-5.2",
            "contextWindow": 1024000,
            "maxTokens": 65536,
            "input": [
              "text"
            ]
          }
        ]
      }`
**设置默认模型**
在 `agents.defaults` 节点下，将主模型指向 Agent Plan 的提供商[-2](https://www.volcengine.com/docs/82379/2373742?lang=zh)[-6](https://docs.openclaw.ai/zh-TW/providers/volcengine.md)：
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "volcengine-agent-plan/ark-code-latest"
      }
    }
  }
}
重启验证：
openclaw gateway restart
验证模型是否加载：
openclaw models list --provider volcengine-agent-plan
