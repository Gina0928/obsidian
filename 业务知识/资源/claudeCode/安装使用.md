安装： npm install -g @anthropic-ai/claude-code
查询npm安装路径：npm root -g
验证： claude -v
### 三种运行模式（按 Shift+Tab 切换）

| 模式           | 说明          | 适用场景                                                                                                                                  |     |
| ------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------- | --- |
| **普通模式**（默认） | 所有操作需手动确认   | 新手、不熟悉的操作                                                                                                                             |     |
| **自动接受模式**   | 自动执行所有操作    | 信任的、简单的任务                                                                                                                             |     |
| **Plan 模式**  | 先生成计划，不执行代码 | 复杂项目的前期规划[-4](https://cloud.tencent.com.cn/developer/article/2573107?policyId=1004)[-7](https://developer.aliyun.com/article/1705912) |     |
设置中转模式：

**Windows PowerShell（一次性，仅当前窗口有效）**

$env:ANTHROPIC_BASE_URL = "https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN = "token"
$env:ANTHROPIC_MODEL = "deepseek-v4-pro"
claude


使用：
|`claude`|启动交互模式（最常用）[-3](https://grapecity.csdn.net/68ff3a960e4c466a32e198bc.html)|
|`claude "任务描述"`|运行一次性任务后退出[-1](https://developer.aliyun.com/article/1710394)|
|`claude -p "查询"`|运行查询后退出（适合脚本调用）[-3](https://grapecity.csdn.net/68ff3a960e4c466a32e198bc.html)|
|`claude -c`|继续最近的对话[-1](https://developer.aliyun.com/article/1710394)|
|`claude -r`|从历史列表中选择并恢复会话|


| `/clear`          | 清除对话历史，开启新对话[-1](https://developer.aliyun.com/article/1710394)                                |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `/help`           | 显示所有可用命令[-1](https://developer.aliyun.com/article/1710394)                                    |
| `/init`           | 生成 CLAUDE.md 项目配置文件[-4](https://cloud.tencent.com.cn/developer/article/2573107?policyId=1004) |
| `/model`          | 切换 AI 模型（如 Sonnet/Opus）[-3](https://grapecity.csdn.net/68ff3a960e4c466a32e198bc.html)         |
| `/cost`           | 查看 token 消耗和费用统计[-3](https://grapecity.csdn.net/68ff3a960e4c466a32e198bc.html)                |
| `/status`         | 查看账户和系统状态[-1](https://developer.aliyun.com/article/1710394)                                   |
| `exit` 或 `Ctrl+C` | 退出 Claude Code                                                                                |

问题：skill-creator需要node版本18+
安装node管理工具：
nvm
1. **下载 nvm-windows**：
    
    - 访问：[https://github.com/coreybutler/nvm-windows/releases](https://github.com/coreybutler/nvm-windows/releases)
        
    - 下载 `nvm-setup.exe`
**安装新版 Node.js**（以管理员身份运行 PowerShell）：
powershell
nvm list available      # 查看可用版本
nvm install lts         # 安装最新 LTS 版本
nvm use lts
例如：
```
nvm install 20
nvm use 20
```
安装skill-creator
npx skills add https://github.com/anthropics/skills --skill skill-creator -a claude-code -g -y
claude
