Q1:RAG和微调模型对比
A1：

|           | RAG            | 模型微调            |
| --------- | -------------- | --------------- |
| 时效性       | 实时更新           | 长时间的重训练         |
| 追溯，幻觉     | 可追溯，解释性强，减少幻觉  | 不可追溯，超出问题容易出现幻觉 |
| 响应        | 响应较慢，拆分成了两个步骤  | 响应快             |
| 深度推理      | 深度推理一般，可能会照搬文档 | 对新问题进行组合推理      |
| 权限控制&风格追求 | 可精准控制权限访问文档    | 可深度定制风格         |
最佳实践：RAG+模型微调
